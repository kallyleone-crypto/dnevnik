# Дневник

Кликабельный макет семейного календаря: общий дневник на несколько телефонов, цвет у каждого члена семьи, разделённая клетка при пересечении слотов и отмена без переписки.

## Открыть макет

Откройте [`index.html`](index.html) в браузере или GitHub Pages после включения Pages в настройках репозитория:

`Settings → Pages → Deploy from a branch → main / root`

После этого макет будет здесь:

https://kallyleone-crypto.github.io/dnevnik/

## Что нажимать

1. Вторник — в 17:00 клетка делится: Марк у стоматолога, Катя на маникюре.
2. «Стоматолог» → «Отменить запись».
3. Переключатель зрителя на Катю — она видит свободный слот без сообщения в чат.
4. «Семья» — цвета и приглашение второго телефона.
5. «+» — новая запись появляется в общем дневнике.

## Стек

Один статический файл: HTML + CSS + JS. Без сборки и бэкенда.
