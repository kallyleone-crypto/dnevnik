# Дневник — макет для заказчика

Кликабельный прототип семейного календаря. Не продукт: без аккаунтов и живой синхронизации.

## Показать заказчику

- Скачайте [index.html](https://github.com/kallyleone-crypto/dnevnik/blob/main/index.html) и откройте в браузере
- Или предпросмотр: https://htmlpreview.github.io/?https://github.com/kallyleone-crypto/dnevnik/blob/main/index.html

Сценарий справа на странице:

1. Неделя как дневник
2. Вторник, 17:00 — клетка делится
3. Отмена без чата
4. Семья и приглашение второго телефона

Переключатель «Телефон Марка / Кати / Ани» имитирует разные устройства.

## После одобрения

Аккаунты, общее облако, уведомления, затем оболочка iOS.
